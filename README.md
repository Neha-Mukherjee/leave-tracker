spring boot management system 

The system currently supports:

- Employee management
- Employee activation/deactivation
- Google OAuth2 authentication
- Leave balance creation and calculation
- Leave request creation
- Leave request retrieval
- Probation validation
- Leave request approval/rejection
- Leave request status validation


Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- Spring Security
- Google OAuth2
- MySQL
- Flyway
- Maven
- Postman
- Git & GitHub
- IntelliJ IDEA
